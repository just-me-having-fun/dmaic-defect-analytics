# DMAIC Defect Analytics

An end-to-end **Six Sigma DMAIC case study** applied to real manufacturing defect data — Define → Measure → Analyze → Improve → Control, with the full statistical toolkit.

## Why

Built alongside my **Lean Six Sigma training** (White Belt certified, Yellow Belt in progress) to prove I can actually run the methodology, not just name it. Root-cause discipline and statistical process control are exactly what reliability and manufacturing operations teams live on.

## What it does

| Phase | Tools | Status |
|---|---|---|
| **Define** | Project charter + SIPOC (`docs/project_charter.md`) | ✅ |
| **Measure** | Synthetic process/defect data generator, Pareto analysis of defect types | ✅ |
| **Analyze** | X̄-R control charts (Shewhart), F-test & Welch t-test, fishbone diagram | ✅ |
| **Improve** | Variance-reduction scenario; DOE notebook planned | 🟡 |
| **Control** | Process capability (Cp/Cpk) before vs after; DPMO → sigma level | ✅ |

Run it: `pip install -r requirements.txt` then `python demo_dmaic.py` and `python demo_analyze.py` (writes Pareto, X-bar and fishbone charts to `outputs/`).

## Dataset

Fully **synthetic** solder-paste assembly process (thickness subgroups + defect log), generated by `src/synth_defects.py` — no real market or client data.

## Tech

- Python 3, pandas, numpy, scipy, statsmodels, matplotlib
- Minitab-style outputs replicated in Python notebooks
